(STARTER RULE — 맞으면 남기고 아니면 지운다.) 사소하지 않은 변경을 완료로 보고하기 전에
실제 흐름을 끝까지 실행해 동작을 관찰한다. 타입 체크나 단위 테스트 통과는 "된다"가 아니다.
같은 확인을 반복하게 되면 일회용 스크립트를 다시 쓰지 말고 `verify-app` 스킬로 승격한다.

**왜:** 검증 없이 나간 변경이 회귀를 실어 나른다.
**적용:** 영향받는 흐름을 돌리고, 관찰한 결과를 근거와 함께 보고한다. 실패했으면 실패했다고
그대로 적는다.
