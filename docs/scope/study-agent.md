# 구현 범위
- window.py: 네 가지 표시 상태와 독립 토글, 영상 전환/종료 보호.
- window.py: 우클릭 속도 조절 행과 설정의 단축키 안내.
- ai/panel.py: 질문+답변 삽입, 메모 생성/영상 캡처 동작, 전송 첨부 관리.
- notes/panel.py: 에이전트만 열 때 수정하지 않은 빈 메모 파일 자동 생성 방지.
- ai/study.py: Q&A 원문 변환, 요약 입력과 GTK 미리보기/취소/적용.
- 단위 및 격리 GTK 시나리오: Q&A/표시/요약/캡처/보존 경계.
- 기존 시나리오는 메모만 열면 대화도 열린다는 가정을 새 독립 표시 계약에 맞춘다.
- 기존 GitHub CI에 신규 학습 에이전트 격리 시나리오 실행을 추가한다.
- window.add_pin/notes.append_pin: 장면 캡처와 시간 링크, 이미지 앞 제목 커서, 실패 알림.
- StudyPreview: 비모달 창과 현재 메모 스냅샷 포함 선택. 요약 중 편집한 메모는 보존한다.
