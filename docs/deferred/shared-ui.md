# 공통 UI 후속 작업

## Windows 후속
동일 UI 소스로 실제 한국어 IME, Ctrl+Enter/Ctrl+W, 기본/최소 창, 밝게/어둡게,
100/125/150/200% 및 모니터 간 배율 전환을 검증한다. 필수 아이콘과 GTK/libadwaita/
PyGObject/libmpv 런타임 조합을 배포 기록에 고정하고 portable 설치/재시작을 검사한다.
OS별 화면 복제 없이 platform/ 어댑터 문제와 공통 UI 문제를 분리해 수정한다.

## 이후 공통 개선
- 타임라인의 역할별 색상·텍스트 렌더링 통합과 밝은/어두운/고대비 검토.
- 메뉴/툴바/단축키 공통 액션 목록과 아이콘 리소스 묶음.
- 사용자 테마 선택 설정이 필요하면 저장·재시작·시스템 설정 우선순위까지 별도 설계.
- 실제 고대비 세션·글꼴 배율·스크린리더 및 미검증 Linux 버전 실측.

검증하지 않은 조합을 지원 완료로 기록하지 않는다.
