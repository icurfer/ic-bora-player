# 영상별 학습 에이전트와 장면 메모

포탈 task 361 / harness study-agent / Unreleased. 제품 버전은 유지한다.

## 결과
- 영상에 연결된 메모와 에이전트를 각각 열고 닫는다. 둘 다 열면 위 메모/아래 대화다.
- 메모에 넣기는 질문과 답변을 함께 추가한다. 대화 전체 원문과 AI 요약은 별도 미리보기다.
- 요약은 창을 열 때의 메모를 기본 포함하며 해제 가능하다. 생성 중에도 메모 편집이 가능하다.
  메모 추가 전 저장 충돌을 확인하고 실패 시 삽입분만 되돌려 재시도 중복을 막는다.
- 화면 첨부는 현재 영상 프레임을 캡처한다. 썸네일/제거와 실제 PNG 전송을 제공한다.
- P는 시각과 장면을 메모에 기록하고 이미지 앞 제목에 커서를 둔다. Shift+P는 입력 없이 기록한다.
  캡처 실패 시 시각 핀을 보존하고 알린다. 핀 상태 파일 형식은 바꾸지 않았다.
- 우클릭 메뉴와 환경설정에 속도 단축키 `,`/`.` 및 0.25배 조절을 표시한다.

## UI 검토
독립 검토 에이전트와 실제 GTK 실행 화면을 확인했다. Adwaita 위젯/글꼴을 유지했다.
버튼으로 메모와 에이전트를 구별하고 전송 옵션은 접을 수 있다. 이미지 오류 때는 옵션을 펼친다.
옵션을 접고 요청 640×560에서 실제 내용 크기 630×550, 첨부 네 장 때는 내용에 따라 높이가 늘어난다.
검토 실행의 네 장 상태는 630×626이었다. 전송 옵션을 펼치면 추가 높이가 필요하다.
창의 실제 할당 범위 안에 메모·질문·전송과 썸네일이 있는지 검사했다.
핀 제목이 화면 아래에 숨는 문제는 입력 위치로 스크롤하도록 보완했다.

## 구분과 후속
- 요약은 메모/대화의 텍스트를 정리한다. 이미지 이름만으로 내용을 추측하지 않도록 지시한다.
  이미지 이해가 필요하면 대화에 실제 이미지를 첨부한다. 실제 모델 품질은 미검증이다.
- 전송 이미지 최대 4장/20MB 정책 유지. 메모 이미지가 많으면 전송 옵션에서 제외할 수 있다.
- 전송 전 캡처 목록은 세션 메모리, 전송한 이미지 경로와 대화는 파일에 남는다.
- Xvfb 키입력 검증과 실제 Wayland 재생 검증을 구분한다. 한국어 IME와 Windows 실측은 후속이다.
- 로컬 패키지 빌드·설치는 하지 않는다. push 후 GitHub CI의 개발 deb 검증/업로드 결과는
  포탈 task 361에 커밋·실행 링크로 기록한다. 정식 Release와 로컬 설치 완료를 뜻하지 않는다.
