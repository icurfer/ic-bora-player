## 바뀐 동작

- 음성 트랙만 있는 파일에는 영상 트랙이 없다는 안내를 표시한다. 실제 문제 파일은 WAV였다.
- 다른 파일을 열 때 이전 타임라인·검은 덮개·클립·에디터·지연 콜백을 정리한다.
  편집이 남아 있으면 같은 전환을 다시 시도하기 전에 폐기 안내를 보여 준다.
- 메모 저장 충돌·오류가 있으면 파일 전환과 종료를 막고 버퍼를 보존한다.
- AI 답변은 질문 아래의 마크에 넣는다. 문서 전환과 종료는 요청을 취소하고 오래된 응답을 무시한다.
- 내보내기에서 원본 경로·심볼릭 링크·하드 링크·번호가 붙은 출력의 원본 충돌을 차단한다.
  합치기는 고유 임시 파일을 성공 후 교체하며 실패·취소 시 기존 결과를 보존한다.
  concat 목록은 임시 파일명만 기록해 폴더의 따옴표 문제를 피한다. stderr 파이프 교착도 제거한다.
- 외부 일반 자막은 sub-files로 전달한다. fuzzy 자동 검색과 다국어 자막은 유지하며 중복은 없다.
- 설정 구조·타입·숫자 범위와 기록·핀을 검사한다. 잘못된 구조는 기존 백업 경로로 옮겨 복구한다.
- 메뉴의 로그 등급을 mpv에도 적용한다. GL 초기화 오류는 로그와 화면에 표시한다.
- 선택 기능 스크립트는 기본적으로 사용자 데이터 폴더에 설치하며 deb에도 포함한다.
  기존 개발 venv를 유지하고 없는 경우 사용자 설치 위치를 찾는다. --dev로 개발 설치를 명시한다.
