# 메모 이미지와 단축키 — 0.26.6

## 구현

- 메모의 마크다운 이미지 링크에서 로컬 PNG·JPEG·WEBP 파일을 찾는다.
  메모 폴더 안의 최대 4장, 합계 20MiB까지 전달하며 원격 URL과 폴더 밖 경로는 허용하지 않는다.
  누락·지원하지 않는 형식·제한 초과를 조용히 생략하지 않고 오류로 안내한다. GIF는 이번 범위에 없다.
- AI 영역에 기본 활성인 메모 이미지 첨부 선택과 개수·오류 안내를 추가했다.
  주변 자막·메모 텍스트 선택과 독립적으로 동작하며, 해제하면 이미지 파일을 읽어 보내지 않는다.
- 이미지 읽기는 작업 스레드에서 수행한다. OpenAI API에는 `input_image` data URL,
  Codex에는 임시 작업폴더로 복사한 `localImage`를 전달한다. 기록에는 파일 이름만 남긴다.
- AI 입력의 키 컨트롤러는 CAPTURE 단계에서 정확한 Ctrl+Enter 조합을 처리한다.
  Enter는 줄바꿈이며 화면에 `Ctrl+Enter 보내기 · Enter 줄바꿈` 안내를 표시한다.
- 메모는 Ctrl+S 저장, Ctrl+T 현재 시각, Ctrl+Shift+S 화면 캡처,
  Ctrl+Enter 외부 Codex 터미널, Ctrl+Shift+Enter 앱 질문 초안을 제공한다.
  앱 질문 초안으로 옮기는 동작 자체는 전송하지 않는다. 메모 도구줄에 단축키 도움을 추가했다.

## 독립 검토

[bora-ui-review](../../.claude/skills/bora-ui-review/SKILL.md)를 적용했다.
사용자가 제공한 화면에서는 마크다운 이미지 링크가 메모에 있었지만 AI가 이미지 자체를
받지 못했다고 답했다. 이번 변경은 링크 문자열과 실제 이미지 첨부를 구분하도록 설계했다.

소스에서 이미지 선택의 독립성, 실제 바이트 전달, 두 제공자의 입력 구성,
첨부파일 이름만 기록하는 동작, 키 이벤트 처리 단계 및 단축키 분기를 검토했다.
현재 검토 범위에서 추가로 확인된 소스 차단 결함은 없다.
다만 이미지 형식 검사는 파일 시그니처 수준이며 전체 이미지 디코딩의 유효성을 보장하지 않는다.

**UI 판정: 미검증.** 이 버전의 실제 실행 화면과 키 이벤트를 확인하지 못했으므로
버튼 배치·포커스·실제 단축키 동작을 통과로 판정하지 않는다. 이전 버전의 화면 검증을
이번에 추가한 이미지 선택·상태·단축키 안내의 증거로 사용하지 않았다.

## 검증 결과

- 관련 단위 테스트 **81건 통과**. 이미지 판독·경로·크기 제한 및 제공자 입력 구성 등을 포함한다.
- 컴파일 및 diff 검사 통과.
- **0.26.6 deb 빌드 완료**.
- `16-shortcuts-images.py` 작성과 컴파일 완료. 이 시나리오는 실제 XTest 키 이벤트,
  OpenAI API와 Codex의 모의 통신을 연결한 이미지 바이트 전달, 첨부 해제,
  제한 초과·폴더 밖 경로 차단, 작은 창과 단축키 도움을 검사하도록 구성했다.
- 실제 키 주입 전에 검증 창의 XID가 포커스인지 확인한다. 다른 창이 포커스이면 중단한다.
  외부 터미널과 제공자 통신을 대체해 실제 계정·질문 과금·사용자 자료를 사용하지 않는다.
- **GUI 검사는 실행하지 못했다.** 현재 실행 환경에서 GTK 디스플레이에 접근할 수 없고
  Xvfb도 없다. 시나리오는 이 경우 미검증 안내와 종료 코드 2를 반환한다.
  실제 실행한 검증 항목은 0건이며, `0/0 통과`로 보고하지 않는다. 이번 버전의 새 캡처도 없다.

GUI 접근이 가능한 환경에서 남은 실행:

```bash
GDK_BACKEND=x11 GSETTINGS_BACKEND=memory \
  BORA_REVIEW_SHOTS=/tmp/bora-images-ui-review \
  python3 .claude/skills/verify-app/scenarios/16-shortcuts-images.py
```

DISPLAY와 XAUTHORITY가 유효해야 한다. 실제 키 포커스 충돌을 피하도록
다른 GUI 시나리오와 동시에 실행하지 않는다. 960×560에서 메모와 AI 입력·전송 버튼,
추가된 이미지·단축키 안내가 함께 접근 가능한지도 확인해야 한다.

## 배포 상태

설치본은 **0.26.5**이며 **0.26.6 로컬 설치는 미완료**다. 현재 실행 환경의
`NoNewPrivs=1` 제한으로 설치 권한을 얻을 수 없다. `.git`도 읽기 전용이므로
커밋과 push는 수행하지 못했다. 소스 변경과 패키지 빌드까지 완료된 상태다.

실제 GUI 검증, 로컬 설치 확인, 커밋·push를 권한이 허용된 환경에서 마무리해야 한다.
실제 계정의 이미지 질의와 다른 OS는 검증하지 않았다.
