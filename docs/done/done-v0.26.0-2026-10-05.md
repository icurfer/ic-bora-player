## §1 비목표를 뒤집었다

기획서 v0.1 §3 에 "Windows·macOS 를 지원하지 않는다"를 적었다. 근거는 "윈도우엔
팟플레이어가 있고 국내 자막을 잘 다룬다" 였다. **자막만 보고 한 말이었다.**

> 윈도우에서도 사용하고 싶다. 광고 그런 거 불편하고, 우리 플레이어처럼 유틸 기능들이 없다.

v0.3 부터 이 앱은 메모·핀·구간 반복·컷 편집·텍스트 추출·AI 질의까지 가는 학습 도구가 됐고,
그건 윈도우에도 없다. macOS·Android 는 폴더만 뒀다(§4).

### 3-1. 플랫폼 폴더

```
platform/base.py        지켜야 할 이름과 뜻 (시그니처는 동작하는 리눅스 구현에 맞췄다)
platform/__init__.py    런타임에 하나를 고른다
platform/linux/     ✅  gl=EGL        integration=xdg (기존 desktop.py 이전)
platform/windows/   🚧  gl=WGL+폴백   integration=없음(이유 표시)
platform/macos/     📋  gl=미구현
platform/android/   📋  gl=의미 없음
```

**윈도우 GL 의 핵심**: `wglGetProcAddress` 는 OpenGL 1.1 핵심 함수에 NULL 을 준다.
`current_fbo()` 가 쓰는 `glGetIntegerv` 가 바로 그것이라 **`GetProcAddress` 폴백이
없으면 화면이 검게 나온다.** 리눅스에서 겪은 증상과 같은 모양이라 알아보기 어렵다.

### 3-2. 추측 코드를 넣지 않았다

macos·android 의 `gl.available()` 은 `False` 를 돌려 렌더를 시도조차 하지 않는다.
그럴듯한 빈 구현을 넣어두면 **"되는 줄 알았는데 안 되는"** 상태가 되고, 그건 아예 없는
것보다 나쁘다. 대신 각 `__init__.py` 에 무엇이 다르고 무엇이 막히는지 적었다.

## §4 안드로이드에 대한 판단

**포팅이 아니라 새 프로젝트다.** GTK 는 안드로이드를 지원하지 않는다 — 공식 백엔드가 없다.
UI 를 통째로 새로 짜야 하고(터치·세로 화면), 파이썬도 앱에 끼워 넣어야 하며,
파일 접근이 경로가 아니라 SAF URI 다.

가져갈 수 있는 것은 **로직층 약 2,500줄**(자막 725줄이 핵심). 현실적인 길은
Kotlin 앱 + libmpv 에 자막 로직을 옮기거나 Chaquopy 로 끼우는 것이다.

## §5 검증 쪽에서 고친 것

전체 시나리오를 처음으로 한 번에 돌렸고 3건이 실패했는데 **전부 검사 쪽 문제**였다.
그중 하나는 **지난번에 "고쳤다"고 말한 것이 실은 안 고쳐져 있었다.**

| 결함 | 원인 |
|---|---|
| 03 볼륨 · 04 자막 위치 | **설정 격리가 늦었다.** `win.state = State(임시폴더)` 는 창이 `_apply_settings()` 로 사용자 설정을 player 에 적용한 **뒤**다. 최근 파일이 안 쌓이는 것만 보고 격리됐다고 판단했다 → `XDG_CONFIG_HOME` 을 import 전에 세운다 |
| 03 메뉴 6건 | 메뉴를 `ScrolledWindow` 로 감싼 뒤 검사가 직계 자식만 훑어 빈손 → 재귀 탐색 |
| 03 우클릭 좌표 | 화면 안으로 당기는 보정이 들어간 뒤 "클릭 지점과 똑같은가"는 틀린 기준 → "좌상단이 아니고 근처인가" |
| 03 간헐 실패 | 전체화면 전환 뒤 렌더를 기다리지 않고 셌다 → `wait_until` |

그리고 **01 은 영상 인자가 필요한데** 내가 인자 없이 돌려 "출력 없음"이 나왔다.
`SKILL.md` 에 시나리오 표와 돌리는 법을 적었다.
