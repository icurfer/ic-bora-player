# plan-v0.3.0 — 보면서 배우는 도구

작성: 2026-09-14 · 상태: **기획 · 구현 대기**
이전: [`plan-v0.2.0.md`](plan-v0.2.0.md) (v0.2 완료, `version` 0.9.0)
요구 출처: 2026-09-14 대화 (텍스트 추출 · 학습 메모 · AI 질의)

## §0 제품 정의를 다시 쓴다 ⚠ 이 절이 이 기획의 핵심

v0.1 의 정의는 **"국내 자막을 제대로 다루는 플레이어"** 였다. 그런데 실제 사용이 달랐다.

> "대학원 수업이나 외부 강의를 로컬로 재생하는 경우가 있는데, 학습하면서 메모를 바로바로 하기가
> 손으로 종이에 쓰는 것보다 컴퓨터가 더 편하다. 타이핑이 더 빠르기 때문."
> — 사용자, 2026-09-14

**새 정의: 로컬 강의 영상으로 공부하는 사람을 위한 학습 도구.**

| | v0.1~v0.2 | v0.3 |
|---|---|---|
| 무엇 | 자막이 제대로 나오는 플레이어 | **강의를 보고, 받아 적고, 되묻는 도구** |
| 주 사용자 | 국내 자막으로 영화를 보는 사람 | **로컬 강의로 공부하는 사람** |
| 자막의 역할 | 목적 | **수단** — 강의 내용을 글로 붙잡는 통로 |
| 성공 기준 | 자막이 그냥 나온다 | **강의를 본 뒤 남는 것이 있다** |

자막 기능은 버리지 않는다. 오히려 **토대**가 된다 — 자막이 있어야 검색·질의가 가능하고,
자막이 없으면 만들어야 한다(§2). 국내 자막 처리는 여전히 이 도구의 차별점이다.

### 0-1. 그래도 하지 않는 것

정의가 넓어지면 무엇이든 넣고 싶어진다. 경계를 먼저 못박는다.

- **영상 편집**(자르기·합치기·인코딩) — 플레이어가 아니게 된다
- **노트 앱**(태그·역링크·그래프·동기화) — Obsidian 이 할 일이다. 우리는 **평문 마크다운 파일**만 만든다
- **강의 관리**(수강 목록·진도율·일정) — 학습 관리 시스템이 아니다
- **클라우드 계정·서버** — 전부 로컬에서 끝난다. AI 질의만 사용자의 API 키로 나간다

## §1 조사 — 이미 있는 것들 (2026-09-14)

| 방식 | 예 | 한계 |
|---|---|---|
| 노트 앱에 영상을 끌어들임 | Obsidian 플러그인(Media Extended, Youtnote, Timestamp Notes) | 노트가 주·영상이 부수. 로컬 영상 재생이 어설프다 |
| 브라우저 확장 | HoverNotes | 웹 영상 전용 |
| **플레이어에 노트를 넣음** | **FrameNote**(Tauri+React) | **거의 같은 발상이 이미 있다** |

정직하게: **FrameNote 가 선례다.** `recording.mp4` 를 열면 옆에 `recording.md` 를 만들고,
마크다운을 정본으로 삼고, 클릭하면 그 시점으로 점프한다. 재생 위치 자동 저장, whisper 연동,
Ollama/Gemini 분석까지 있다.

**그래서 Bora 가 다른 점을 분명히 해야 한다:**
1. **국내 자막 처리** — CP949·SAMI·빈 큐 정리. FrameNote 에 없다
2. **자막 에디터** — 보면서 싱크를 고치고 저장한다(v0.2)
3. **GTK 네이티브** — 웹뷰가 아니다. Wayland 에서 가볍다
4. 한국어 UI 와 국내 학습 맥락

**가져올 것**: 마크다운 사이드카를 **원본 옆에 두고 정본으로 삼는다**는 설계.
우리가 자막에서 지켜 온 원칙("원본을 함부로 덮지 않는다", "평문으로 둔다")과 같다.

## §2 텍스트 추출 — 자막이 없으면 만든다

강의 영상에는 자막이 없는 경우가 많다. 자막이 없으면 §3 의 메모·질의도 반쪽이 된다.

### 2-1. 무엇을 쓰나

**faster-whisper** — infra 런북 §23 에 이 머신에서 쓴 기록이 있다(`large-v3`, CPU int8,
한국어 통화 녹음 성공). ⚠ 다만 **지금은 설치돼 있지 않다**(venv 를 프로젝트 폴더에 두는 방식이라
그 프로젝트와 함께 사라졌다). Bora 안에 `.venv-stt` 로 다시 만든다.

| 결정 | 이유 |
|---|---|
| 별도 venv(`.venv-stt`)에 둔다 | 시스템 파이썬은 PEP 668 로 막혀 있고, 무거운 의존성을 앱 본체와 섞지 않는다 |
| **선택 기능으로 둔다** | 설치 안 해도 플레이어는 그대로 동작해야 한다. 없으면 메뉴에 "설치가 필요하다"를 보여 준다 |
| 별도 프로세스로 실행 | 모델 로딩과 추출이 무겁다. 앱이 멈추면 안 된다 |
| 결과는 **SRT 로 저장** | 우리 자막 파이프라인(판정·분리·편집)에 그대로 얹힌다 |

### 2-2. 흐름

```
자막 없는 강의를 연다 → "자막이 없다. 음성에서 추출할까요?" (토스트)
  → 모델 선택(tiny/base/small/medium/large-v3) · 언어(자동/한국어/영어)
  → 별도 프로세스로 추출. 진행률 표시. 취소 가능
  → <영상이름>.ko.srt 로 저장 → 자막으로 바로 로드
  → 어긋나면 v0.2 의 자막 에디터로 고친다
```

### 2-3. 주의

- **오래 걸린다.** 1시간 강의를 CPU `large-v3` 로 돌리면 수십 분이다. 모델 크기를 고르게 하고
  예상 시간을 보여 준다. GPU(CUDA)가 있으면 쓰되, 이 머신은 CPU 기준으로 설계한다
- 추출 텍스트는 **초안**이다. 사람 이름·전문 용어가 자주 틀린다. 에디터로 고칠 수 있어야 한다
- 원본 영상은 **절대 건드리지 않는다**

## §3 학습 메모 — 마크다운 사이드카

### 3-1. 원칙

**`<영상이름>.md` 를 영상 옆에 만들고, 그 파일이 정본이다.**
Bora 없이도 읽고 고칠 수 있어야 한다(Obsidian·VS Code·메모장 무엇으로든).

```markdown
# 분산시스템 3주차

## [00:12:34] 합의 알고리즘
Paxos 와 Raft 의 차이 — Raft 는 리더를 먼저 뽑는다

## [00:25:10] 질문
- 네트워크 분할이 나면 어떻게 되나?
```

`[00:12:34]` 를 클릭하면 그 시점으로 이동한다. **평문이라 우리 앱 밖에서도 의미가 있다.**

### 3-2. UI

| 요소 | 설계 |
|---|---|
| 배치 | **우측 패널**(기본) / 별도 창 전환 가능. 전체화면에서는 감춘다 |
| 편집기 | `Gtk.TextView` 기반 평문 편집 + 마크다운 문법 강조. **미리보기는 넣지 않는다**(범위) |
| 타임스탬프 삽입 | 단축키 하나(`Ctrl+T`)로 현재 시각을 `## [HH:MM:SS] ` 로 삽입하고 커서를 뒤에 둔다 |
| 타임스탬프 이동 | 본문의 `[HH:MM:SS]` 를 클릭(또는 `Ctrl+클릭`)하면 그 시점으로 재생 이동 |
| 저장 | 자동 저장(입력 멈춘 뒤 2초, 파일 전환·종료 시). 원자적 쓰기 |
| 스크린샷 첨부 | `Ctrl+Shift+S` → 현재 화면을 `<영상이름>.assets/` 에 저장하고 `![](경로)` 삽입 |

**타이핑 흐름을 끊지 않는 것이 최우선이다.** 사용자가 이 기능을 원한 이유가 "타이핑이 더 빠르기 때문"이다.
일시정지·타임스탬프·저장이 전부 키보드로 끝나야 한다.

### 3-3. 하지 않는 것

- ~~마크다운 렌더링 미리보기(WYSIWYG)~~ → **넣었다(2026-09-14 정정)**. `#` 이 그대로 보이는 것이
  메모하기 불편하다는 지적을 받았다. 다만 **완전한 WYSIWYG 는 아니다** — Obsidian 의 라이브
  프리뷰처럼 커서가 없는 줄만 마크업을 감추고, 커서가 간 줄은 원본을 드러낸다.
  `Gtk.TextTag` 의 `invisible`·`scale`·`weight` 로 하므로 편집기를 새로 만드는 일이 아니다.
  이미지 렌더링·표·수식은 여전히 넣지 않는다
- 노트 검색·태그·역링크 — Obsidian 영역
- 여러 영상의 노트를 한데 모아 보기

## §4 AI 질의 — 메모를 클릭해 되묻는다

### 4-1. 무엇을 푸나

강의를 듣다 모르는 것이 생기면 지금은 브라우저를 열어 검색한다. 그 사이 흐름이 끊긴다.
**메모에 적어 둔 것을 그 자리에서 물어볼 수 있으면** 흐름을 유지할 수 있다.

### 4-2. 흐름

```
메모에 "Paxos 와 Raft 차이?" 라고 적는다
  → 그 줄에 커서를 두고 [물어보기] (Ctrl+Enter)
  → 맥락: 그 줄 + 앞뒤 메모 + 그 시점 앞뒤 자막 + 강의 제목
  → 답이 스트리밍으로 그 아래에 삽입된다 (> 인용 블록)
  → 마음에 안 들면 되돌리기(Ctrl+Z) 한 번으로 지운다
```

**답도 메모 파일에 남는다.** 따로 보관하지 않는다 — 나중에 읽을 때 질문과 답이 같이 있어야 한다.

### 4-3. 설계 결정

| 항목 | 결정 | 이유 |
|---|---|---|
| 공급자 | **Claude API**(`anthropic` SDK) | 사용자가 Claude 를 쓰고 있고, 한국어 품질이 좋다. 로컬 LLM(Ollama)은 이 머신에 없고 강의 맥락을 다루기엔 작은 모델이 부족하다 |
| 모델 | **`claude-opus-5`** | 기본값. 설정에서 `claude-sonnet-5`(더 싸다)로 바꿀 수 있게 한다 |
| 사고 | adaptive thinking | 개념 질문에 유리하다 |
| 응답 | **스트리밍** | 답이 길 수 있고, 기다리는 동안 뭔가 보여야 한다 |
| 맥락 캐싱 | **자막 전체를 프롬프트 캐시에 올린다** | 같은 강의에 여러 번 물으면 입력이 반복된다. 캐시로 최대 90% 절감 |
| 키 보관 | **앱이 키를 저장하지 않는다.** `ANTHROPIC_API_KEY` 환경변수 또는 `ant auth login` 프로필을 읽는다 | 평문 설정 파일에 키를 두지 않는다. SDK 가 알아서 찾는다 |
| 없을 때 | AI 기능만 비활성. 안내를 보여 준다 | 메모·재생은 키 없이도 전부 동작해야 한다 |
| 비용 표시 | 답변마다 토큰 수와 추정 비용을 상태줄에 | 사용자가 자기 돈이 나가는 것을 알아야 한다 |

### 4-4. 맥락을 어떻게 만드나 (중요)

무턱대고 자막 전체를 넣으면 비싸고 느리다. 층을 나눈다.

```
system  : "강의를 보며 공부하는 사람을 돕는다. 한국어로 간결하게 답한다.
           자막에 없는 내용은 추측하지 말고 모른다고 말한다."   ← 고정(캐시)
[캐시]   : 강의 자막 전체 (있으면)                              ← 강의마다 한 번(캐시)
user    : 지금 시점 앞뒤 5분 자막 + 메모의 해당 줄 + 앞뒤 메모   ← 매번 바뀜
```

**고정 부분을 앞에, 바뀌는 부분을 뒤에** 둔다(프롬프트 캐싱은 접두 일치라 순서가 중요하다).

### 4-5. 하지 않는 것

- 자동 요약·자동 질문 생성 — 사용자가 원할 때만 부른다. 돈이 나가는 기능은 자동으로 돌리지 않는다
- 대화형 채팅 UI — 메모가 대화 기록이다. 별도 채팅창을 만들지 않는다
- 에이전트·도구 사용 — 질의응답 한 번이면 된다

## §6 성공 기준

| # | 시나리오 | 기대 |
|---|---|---|
| N1 | 강의를 열고 `Ctrl+T` | `## [00:12:34] ` 가 삽입되고 커서가 그 뒤에 온다. 재생은 계속된다 |
| N2 | 메모를 쓰고 2초 기다린다 | `<영상이름>.md` 가 영상 옆에 저장된다 |
| N3 | 본문의 `[00:12:34]` 클릭 | 그 시점으로 재생이 이동한다 |
| N4 | 앱을 닫고 다시 연다 | 메모가 그대로 있다. 편집을 이어서 한다 |
| N5 | Bora 없이 그 `.md` 를 연다 | 평문 마크다운으로 읽힌다 |
| T1 | 자막 없는 영상을 연다 | "음성에서 추출할까요?" 를 묻는다 |
| T2 | 추출 실행 | 진행률이 보이고 취소된다. 끝나면 `.srt` 가 생기고 자막으로 붙는다 |
| T3 | STT 미설치 상태 | 플레이어는 정상. 추출 메뉴만 "설치 필요" |
| A1 | 메모 줄에서 `Ctrl+Enter` | 답이 스트리밍으로 그 아래 인용 블록에 들어온다 |
| A2 | API 키 없음 | AI 기능만 비활성, 안내 표시. 나머지는 정상 |
| A3 | 같은 강의에 두 번째 질문 | 캐시가 걸려 입력 비용이 크게 준다(`cache_read_input_tokens` 확인) |
| A4 | 답변 후 `Ctrl+Z` | 삽입된 답이 통째로 지워진다 |

## §7 위험

| 위험 | 완화 |
|---|---|
| **제품이 무엇인지 흐려진다** | §0-1 의 '하지 않는 것'을 지킨다. 새 요청이 올 때마다 그 목록에 비춰 본다 |
| **AI 비용이 예상보다 크다** | 자동 호출 금지, 답변마다 비용 표시, 캐싱, 모델 선택(Sonnet 5 로 낮출 수 있게) |
| API 키가 유출된다 | **앱이 키를 저장하지 않는다.** 환경변수·`ant` 프로필만 읽는다. 로그에 절대 남기지 않는다 |
| 메모 파일이 깨진다 | 원자적 쓰기. 자동 저장 전 원본을 메모리에 들고 있는다. `.md` 는 평문이라 복구가 쉽다 |
| 텍스트 추출이 너무 느려 쓸모없다 | 모델 크기 선택 + 예상 시간 표시 + 취소. 기본을 `small` 로 두고 품질이 필요하면 올리게 한다 |
| 노트 패널이 영상을 좁힌다 | 접을 수 있게. 전체화면에서는 자동으로 감춘다. 별도 창 전환 지원 |
| STT 의존성이 앱을 무겁게 한다 | **선택 기능.** 별도 venv, 없으면 그 메뉴만 비활성 |

## §8 확인할 것 (구현 전)

| # | 확인 | 왜 |
|---|---|---|
| 8-1 | `Gtk.TextView` 로 마크다운 문법 강조를 어디까지 할 수 있나 | ⚠ **GtkSourceView 는 이 머신에 없다**(실측). 의존성을 늘리지 않기 위해 **1단계는 `Gtk.TextView` 로 시작**하고, 강조는 `TextTag` 로 최소한만 한다. 필요해지면 그때 `gir1.2-gtksource-5` 를 검토한다 |
| 8-2 | 타임스탬프 클릭 처리 방법 | `TextTag` + `event` 로 되는지, 아니면 별도 처리가 필요한지 |
| 8-3 | faster-whisper 설치 용량과 1시간 강의 추출 시간(CPU) | 사용자에게 보여 줄 예상 시간의 근거. `small` 과 `large-v3` 를 비교한다 |
| 8-4 | `anthropic` SDK 를 시스템 파이썬에 넣을 수 있나(PEP 668) | ✅ **해법 확정(실측)**: 시스템 파이썬에는 **넣을 수 없다**(PEP 668, `externally-managed-environment`). 대신 **`python3 -m venv --system-site-packages .venv`** 로 만들면 시스템 PyGObject·python-mpv 를 그대로 보면서 `anthropic` 을 넣을 수 있다 — GTK 4.22 + anthropic 1.5.0 동시 사용 확인. venv 용량 45 MB. **앱 실행이 `.venv/bin/python -m bora` 로 바뀐다** |
| 8-5 | 프롬프트 캐싱 최소 토큰과 실제 절감 | 짧은 자막은 캐시가 안 걸린다. 강의 자막이 그 기준을 넘는지 |
| 8-6 | 답변 스트리밍을 `Gtk.TextBuffer` 에 넣을 때의 깜빡임 | 매 토큰 삽입이 UI 를 얼마나 바쁘게 하는지. 묶어서 넣어야 할 수도 |

## §8-1 실행 환경 결정 (8-4 의 결과)

`anthropic` 을 쓰려면 venv 가 필요하다. 그런데 PyGObject 는 시스템 GI 와 묶여 있어 순수 venv 에서는
깨진다. **`--system-site-packages` venv** 가 둘을 모두 만족한다.

```bash
python3 -m venv --system-site-packages .venv   # 시스템 GI·mpv 를 그대로 보면서
.venv/bin/pip install anthropic                 # 추가 의존성만 venv 에
.venv/bin/python -m bora <영상>
```

| | 어디에 |
|---|---|
| PyGObject · GTK4 · libadwaita · python-mpv | 시스템(apt) — 그대로 |
| `anthropic` (AI 질의) | `.venv` (45 MB) |
| `faster-whisper` (텍스트 추출) | **별도** `.venv-stt` — 무겁고 선택 기능이다 |

**AI 와 STT 의 venv 를 나누는 이유**: STT 는 수백 MB 에 모델까지 받는다. AI 만 쓰려는 사람에게
그 부담을 지우지 않는다. 둘 다 없어도 플레이어는 그대로 동작한다.

`scripts/install-desktop.sh` 와 `bora` 실행기가 `.venv` 가 있으면 그것을, 없으면 시스템 파이썬을
쓰도록 고친다.

## §9 순서

1. **노트 패널** (N1~N5) — AI·STT 없이 단독으로 쓸모가 있다. 가장 먼저 값을 준다
2. **텍스트 추출** (T1~T3) — 자막이 없는 강의를 살린다
3. **AI 질의** (A1~A4) — 앞의 둘이 있어야 맥락이 생긴다

각 단계가 끝날 때마다 동작하는 상태를 유지한다. 1번만으로도 "강의 보며 메모"는 완성된다.
