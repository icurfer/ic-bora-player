# 포탈 task 관리 정책

포탈 task: 350 · 로컬 하네스: `task-management`.

기준: 기존 공통 UI 후속 기획과 프로젝트 작업 절차에 포탈 인계 채널을 추가한다.

## 배치 위치
정책 정본은 `docs/TASK_MANAGEMENT.md`, 대상 선언은 `.claude/task-space`에 둔다.
AGENTS.md와 CLAUDE.md 공통 블록 및 praxis 작업 진입점에서 이 정책을 읽는다.

## 설정·비밀값 보관 위치
공개 선언에는 ic-bora 스페이스 ID 26과 허용 범위만 저장한다. 로그인 자격은 각 PC의
사용자 설정에 보관하고 저장소·task·댓글에 넣지 않는다.

## 따르는 기존 패턴
task-register 공통 helper의 범위 제한과 명의 구분, 기존 praxis 검증 절차를 사용한다.
제품 버전·릴리스 정책은 변경하지 않는다. 사용자 생성 스페이스를 재사용한다.

## 흐름
시작할 때 목록·상세·댓글을 확인하고 기존 task를 재사용한다. 명시된 사용자 작업 범위의
착수·검증·인계를 기록한다. 포탈에는 현재 상태와 담당, 저장소에는 상세 기획·검증 근거를
두며 task ID와 커밋 링크로 연결한다. Linux 완료와 Windows 후속을 구분한다.
다른 에이전트의 작업을 임의로 가져오거나 대량 등록·초대·삭제하지 않는다.

## 수용
Codex 명의로 스페이스 26 조회·멤버십 확인, 선언 기본 대상과 범위 밖 거부 확인,
정책 작업 1건 등록·조회·상태·인계 댓글 확인, 공통 지침 일치와 하네스 검사.
